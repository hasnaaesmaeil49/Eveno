# Eveno – Event Management Mobile Application

Eveno is a mobile application developed as a graduation project at Al-Azhar University. It is designed to support event management and reservations using Flutter and Firebase.

🚀 Technologies Used

- Flutter & Dart: For mobile application development.
- Firebase Authentication: For user authentication.
- Cloud Firestore: For storing and managing application data.

✨ Features

- User authentication.
- Event management.
- Reservation management.
- Firebase integration for application data.

🛠️ Development Tools

- Flutter SDK
- Dart SDK
- Android Studio
- Firebase

⚙️ How to Run the Project

Prerequisites

Make sure Flutter and Dart are installed and configured on your development environment.

Installation

1. Clone this repository:
   
   git clone https://github.com/hasnaaesmaeil49/Eveno.git

2. Navigate to the project folder:
   
   cd Eveno

3. Install the project dependencies:
   
   flutter pub get

4. Configure Firebase using the project's required configuration files.

5. Run the application:
   
   flutter run
